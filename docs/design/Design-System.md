# XEEO Design System

## Version

v1.0

---

# Design Philosophy

Simple.

Modern.

Developer-first.

Professional.

Fast.

Inspired by the clean experience of modern productivity tools while establishing its own visual identity.

# Brand Personality

* Intelligent
* Collaborative
* Minimal
* Trustworthy
* Modern

Bold

Large

Readable

Body

Comfortable line spacing

Code

Monospace font

---

# Border Radius

* Buttons → Medium
* Cards → Large
* Dialogs → Large
* Inputs → Medium

Rounded but professional.

---

# Shadows

Use subtle elevation only.

Avoid heavy shadows.

---

# Spacing Scale

* 4 px
* 8 px
* 12 px
* 16 px
* 24 px
* 32 px
* 48 px
* 64 px

All layouts should follow this spacing system.

---

# Buttons

Primary

Filled

Used for important actions.

Secondary

Outlined

Lower emphasis.

Danger

Red

Delete actions only.

Text Button

Minimal

Navigation or utility actions.

---

# Inputs

Consistent height.

Clear labels.

Helpful validation messages.

Support keyboard navigation.

---

# Cards

Used for:

* Projects
* Community Posts
* AI Suggestions
* Dashboard Widgets

Every card should include:

* Title
* Description
* Metadata
* Primary Action

---

# Icons

Use one consistent icon library throughout the application.

Icons should communicate function without overwhelming the interface.

---

# Navigation

Left Sidebar

* Dashboard
* Workspaces
* Projects
* Community
* AI
* Notifications
* Profile

Top Bar

* Search
* Workspace Switcher
* User Menu

---

# Motion

Animations should feel quick and purposeful.

Recommended durations:

* Hover: 150ms
* Click: 100ms
* Page transition: 250ms
* Modal: 200ms

Avoid decorative animations that distract from work.

---

# Accessibility

* Keyboard navigation for all major features.
* High color contrast.
* Visible focus indicators.
* Responsive layouts.
* Clear error messages.

---

# Responsive Breakpoints

* Mobile
* Tablet
* Laptop
* Desktop
* Ultra-wide

The experience should remain consistent across all screen sizes.
