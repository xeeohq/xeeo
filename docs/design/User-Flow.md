# Design Goals

Every major action should require as few steps as possible.

* Create a workspace in under one minute.
* Create a project in under one minute.
* Invite teammates in under thirty seconds.
* Find important information within three clicks.
* Keep the dashboard focused on active work rather than unnecessary clutter.

---

# Navigation Principles

* Dashboard is the home screen after login.
* Projects are easier to reach than chat.
* AI assistance should be available from every major page.
* Community should inspire users without distracting them from their work.
* Settings should stay out of the primary workflow.

---

# Success Criteria

A new user should be able to:

* Create an account.
* Create or join a workspace.
* Create a project.
* Invite teammates.
* Begin collaborating.

...without needing a tutorial or external documentation.

If users can accomplish these tasks naturally, the user experience is successful.
