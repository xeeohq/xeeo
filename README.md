# XEEO

> The collaborative platform for modern software teams.

---

## Tech Stack

- Next.js
- NestJS
- TypeScript
- PostgreSQL
- Prisma
- Tailwind CSS
- Turborepo
- pnpm

## Project Structure


## Getting Started

Install dependencies

```bash
pnpm install
```

Run development

```bash
pnpm dev
```
